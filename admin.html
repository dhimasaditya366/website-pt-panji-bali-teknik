publish Cara mempublikasikan perubahan

Situs ini statis (tanpa server/database), jadi "Simpan Perubahan" hanya menyimpan ke browser ini (localStorage) agar Anda bisa terus mengedit dan melihat pratinjau di tab "Lihat Situs". Perubahan itu belum terlihat oleh pengunjung lain. Untuk mempublikasikannya: klik "Unduh data.js" di bagian bawah halaman ini, lalu ganti file assets/js/data.js di hosting Anda dengan file yang diunduh, dan unggah ulang/redeploy situsnya.

✓ Sinkronisasi otomatis ke GitHub aktif — tombol "Simpan Perubahan" langsung mempublikasikan ke situs ini. Perubahan biasanya tampil untuk pengunjung lain dalam 1–2 menit.

⚙️ Pengaturan sinkronisasi otomatis ke GitHub (sekali setting, untuk admin teknis)

Isi sekali saja di perangkat/browser ini. Setelah tersimpan, siapa pun yang login ke admin ini (termasuk yang tidak paham teknis) cukup klik "Simpan Perubahan" seperti biasa — perubahannya otomatis ter-publish ke GitHub Pages, tanpa perlu impor/unduh JSON lagi.

Cara buat token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → New token. Pilih "Only select repositories" → repo ini saja → Permissions → Contents: Read and write. Token tersimpan hanya di browser ini (localStorage), tidak pernah ikut ter-publish ke kode situs.
