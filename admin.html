⚙️ Cadangan manual: sinkronisasi via token GitHub pribadi (opsional, untuk admin teknis)

Publikasi otomatis di atas sudah aktif dan tidak butuh pengaturan apa pun di sini. Panel ini hanya cadangan kalau suatu saat publikasi otomatis itu tidak bisa dijangkau — isi sekali di perangkat/browser ini untuk pakai token GitHub pribadi sebagai jalur alternatif.

Cara buat token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → New token. Pilih "Only select repositories" → repo ini saja → Permissions → Contents: Read and write. Token tersimpan hanya di browser ini (localStorage), tidak pernah ikut ter-publish ke kode situs.
