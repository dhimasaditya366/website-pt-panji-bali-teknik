## Recommended execution order

**005 → 001 → 002 → 003 → 004 → 006**

Plan numbers are ordered by severity (matching the audit table), not execution order — 005 must run first even though it's numbered last-but-one, because both 001 (kontak.html's `card-hover` rule) and 004/006 (which append to `assets/css/motion.css`) depend on the shared stylesheet and `--ease-out`/`--ease-in-out` custom properties it creates.

## Dependencies

- **005 blocks 001, 004, 006** — all three reference `var(--ease-out)` / `var(--ease-in-out)` or append to `assets/css/motion.css`, which 005 creates.
- **002 is independent** of the others but is easiest to apply after 001 (both touch the same class attributes, so doing 001 first avoids re-locating lines twice). Not a hard dependency — 002's find/append rule works regardless of whether `transition-all` or `transition` is present.
- **003, 004, 006 are independent of each other** and can run in any order relative to one another, as long as 005 has already run.
